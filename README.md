# Credit-Risk-ML-Project-Codec-Technologies
# Credit Risk Modeling Using Machine Learning

## Overview
This project predicts loan default risk using machine learning models.

## Dataset
German Credit Dataset

## Models Used
- Logistic Regression
- Decision Tree
- Random Forest
- XGBoost
- LightGBM

## Performance

| Model | Accuracy |
|---------|----------|
| Logistic Regression | 74.5% |
| Decision Tree | 70.2% |
| Random Forest | 78.9% |
| XGBoost | 81.1% |
| LightGBM | 82.3% |

## Technologies
- Python
- Pandas
- Scikit-learn
- LightGBM
- XGBoost
- Matplotlib
